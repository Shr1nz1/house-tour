# 房屋三维看房

现代奶油风房屋展示，包含七个房间6K全景、v7/v8餐厅效果图对比、餐厅/主卧/厨房三张4K效果图、三维房门开合和穿过门口的漫游，以及带图选款册。

## 在线访问

- 完整看房：https://shr1nz1.github.io/house-tour/
- 直接进入三维漫游：https://shr1nz1.github.io/house-tour/?walk=1
- 手机全景：https://shr1nz1.github.io/house-tour/tour.html

网页公开访问，不需要密码，不依赖原电脑开机或内网穿透。

## 操作

在三维中点击门扇，或用“开门”按钮。门完全打开后，点击门洞中的“进入主卧 / 次卧 / 卫生间”，视角会平滑穿过门口。再次点击已打开的门扇或门洞，也可以进入。

房间内点击“看门口”，可以看到返回公共区域的入口；门仍需完全打开才能通过。关门使用门卡片中的“关门”按钮。房间切换按钮保留为快速查看入口。

三维画质可以在“高清”和“流畅”之间切换，页面会记住选择。高清模式保留2K木纹/织物贴图，增加精细边缘处理及柜缝、墙角和家具接触位置的阴影。停止操作时，画面暂停重复绘制，继续拖动或开门即可恢复。

主卧和次卧为向房内平开的奶白房门，卫生间为沿墙推拉门。全景用于看材质和光照，可开门三维用于空间与移动演示。

## 本地修改

使用 Node.js 22 或更新版本：

```bash
npm ci
npm test
npm run build
```

`src/app.js` 是三维交互，`src/routes.js` 保存门洞位置、房间关系和通行条件。`scripts/build.mjs` 生成可直接静态托管的网页和带版本标识的脚本。

提交构建后的根目录文件到 `main`，GitHub Pages 从 `main` 的根目录发布。`.nojekyll` 保留普通静态文件，所有素材链接均支持仓库子目录。
